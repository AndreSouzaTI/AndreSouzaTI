# Hi, I'm André Souza 👋

**Back-end Software Engineer (Java)** focused on **Spring Boot, REST APIs and microservices**. I also work on the front-end with **Angular** and **React** when a project calls for full stack delivery.

I have corporate experience in healthcare, building Java applications integrated with the MV hospital ERP and Oracle SQL routines for system integrations. I hold a degree in Systems Analysis and Development and a postgraduate specialization in Database Administration. I care about testable code, versioned databases, reproducible Docker setups and documentation someone else can actually follow.
